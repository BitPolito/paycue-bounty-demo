# FAQ

## What is this repository for?

It demonstrates automated contribution rewards: merging a pull request that
closes a bounty issue pays its author.

## How can I receive a bounty reward on Liquid?

Contributors can receive a bounty reward as L-USDT on the Liquid testnet by
registering a Liquid testnet payout address on the demo's bounty board. A
Liquid testnet address uses the `tlq1` prefix (for example, `tlq1…`).
