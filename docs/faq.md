# FAQ

## What is this repository for?

It demonstrates automated contribution rewards: merging a pull request that
closes a bounty issue pays its author.

## How can contributors receive a reward as L-USDT on Liquid?

For bounties that use the Liquid payout rail, the reward is paid as **L-USDT
(Liquid USDT)** to the contributor's Liquid address after the qualifying pull
request is merged.

A Liquid address uses the Liquid network's address format and typically starts
with `tlq1` for Liquid testnet addresses. For example:

```
tlq1…
```

Before submitting a pull request, contributors should register their payout
address on the bounty board. If the bounty instructions allow it, the payout
address can instead be included in the pull request description as:

```
Payout: <your Liquid address>
```

Use your own Liquid address when submitting work. Do not copy an address from
another contributor or from an example.
