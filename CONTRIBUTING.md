# Contributing

Keep changes small and focused. For bounty issues, reference the issue with a
closing keyword (`Closes #1`) in the pull request description so the merge
can be matched to the bounty.

## Use a different payout address

If you want this bounty sent to a different wallet than the one registered on
the bounty board, add `Payout: <address>` on its own line in your pull request
description. The board uses that address for this payout instead of your
registered address. If you omit the line, it uses the address registered for
your GitHub username.
