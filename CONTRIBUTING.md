# Contributing

Keep changes small and focused. For bounty issues, reference the issue with a
closing keyword (`Closes #1`) in the pull request description so the merge
can be matched to the bounty.

## Overriding the payout address

By default, the payout goes to the address registered on the bounty board. To
send the reward to a different wallet, add an optional `Payout: <address>` line
to your pull request description. This is useful when the payout address is not
the one registered on the board, or when you prefer to keep the address out of
the public board.

The `Payout:` line must be on its own line in the pull request description.
